# Monster Slayer:
A 2d game thats both an incremental while borrowing classic rpg elements, you're a human thats been brought back to life by ???? to cleanse the world of the manifestations of the seven deadly sins, You're not what you once were but you do retain one crucial aspects of humans, their limitless ability to grow through hard work and sheer willpower. 

# Setup Instructions:
Itch.io Installation: Unzip the folder and run the MonsterSlayer.exe file
